# AI Agent 自主问题处理方法论

> 作者: MO | 协议: CC BY 4.0

融合 7 大主流 AI Agent 框架的精华，形成一套可复用的自主问题处理流程。

## 核心循环

**观察 → 思考 → 行动 → 观察结果 → 反思**，形成闭环。

## 方法论（9步）

### 0. 定义成功标准
动手前先明确：什么情况算"做完了"？列出可验证的条件。防止无限循环。

### 1. 先搜经验
处理问题前，先搜索有无相关经验文档。搜到就直接复用，跳过已知失败的方法。

### 2. 评估方法
- 方法对不对？符不符合当前环境？
- **风险评估**：可能带来什么副作用？（文件覆盖、端口占用、权限问题）
- 之前试过失败的不要再用

### 3. 写过程文档
记录背景、成功标准、环境、方法、测试结果、下一步、迭代计数（最多10轮）。

### 4. 读写循环
每次行动前读文档确认方向，做完后立刻更新文档。**用文档纠正自己**，不靠短期记忆。

### 5. 失败反思
每次失败后分析：为什么失败？是方法错、环境不对、还是执行有误？
区分"换个方法"和"同一个方法换个参数"。

### 6. 不重复错误
文档里记录过的失败方法，绝对不再尝试。

### 7. 质量验证
解决后自检：是否满足成功标准？有无遗漏边界？代码/文件是否干净？

### 8. 总结沉淀
写明：什么方法有效/无效、关键陷阱、可复用代码片段。方便下次复用。

## 方法论来源

本流程融合了以下框架的精华：
- **Chain of Thought** — 逐步推理，不想当然
- **ReAct** — 观察→思考→行动→观察的循环
- **Reflexion** — 失败后结构化反思，分析根因
- **Self-Refine** — 完成后自检质量，不是跑通就算完
- **Plan-and-Solve** — 先规划再执行，评估风险
- **AutoGPT** — 定义成功标准，防止无限循环
- **Claude Computer Use** — 文件驱动的自主操作模式

## 适用场景

- AI Agent 自主调试代码、修复 bug
- 复杂多步骤任务的自动化处理
- 跨会话的经验积累和知识复用
- 任何需要"自己解决问题"的 AI 工作流
